# 每日名作 (Daily Artwork) 集成

Home Assistant集成，用于每日获取世界名画、名句等信息并在界面中展示。

## 功能特点
- 显示作品名称、作者、图片和简介
## 安装方法
  1. 将此目录复制到Home Assistant的`custom_components`文件夹中


2. 重启Home Assistant
3. 在集成页面搜索并添加"每日名画"

## 使用方法
添加集成后，将自动创建

## 实体属性
传感器包含以下属性:
- `image`: 作品图片URL
- `author`: 作者名称
- `text`: 作品简介（前四行）
